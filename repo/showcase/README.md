# showcase — 보존된 결과물

사이클 실행 결과 중 **비교·시연용으로 남겨 둔 것**. `ops/reset.sh` 도 여기는 건드리지 않는다.

| 폴더 | 무엇 |
|---|---|
| `v1-before/` | 지시문 고도화 **이전** 결과물. 품질 점수 10/19 (53점) |

`repo/runs/<사이클>/` 은 새 사이클이 같은 번호를 쓰면 덮어써진다.
남겨야 할 것은 여기로 복사해 둔다.

```bash
cp -r repo/runs/3/S5/output repo/showcase/v2-after
```

미리보기 주소: `/preview/showcase/<폴더>/index.html`
