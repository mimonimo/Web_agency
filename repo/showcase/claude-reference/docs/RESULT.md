| CSS 변수 | 24개 정의 · 24회 사용 (**정의당 1회**) | 29개 정의 · 170회 사용 (**정의당 5.9회**) |
| | → 변수를 선언만 하고 실제로는 값을 직접 씀 | → 색·간격·글자·모서리를 **전부** 변수로 |

## 4. 이 케이스가 증명하는 것 / 증명하지 못하는 것

**증명하는 것**

- 파이프라인·지시문·검사 체계는 **모델과 무관하게 동작한다.**
  같은 기준선 AGENT.md, 같은 `roles.yaml` 완료조건, 같은 `checks.py` 로 채점했다.
- 좋은 모델을 붙이면 **채점기가 보는 곳은 만점**, 안 보는 곳(접근성·서버 검증·
  변수 활용도)에서 격차가 벌어진다.
- 19항목 채점기는 **상한에 도달했다.** 더 높은 품질을 재려면 항목을 늘려야 한다.

**증명하지 못하는 것**

- 이건 **한 번의 결과**다. 로컬 모델은 같은 조건에서 여러 번 돌려 평균을 봐야 공정하다.
- Claude Code 는 사람과 대화하며 만들었다. 완전 자동 실행(`EXECUTOR=llm`)과는
  조건이 다르다. 자동 실행 비교는 별도로 해야 한다.
- 실행 시간·비용을 재지 않았다. 로컬 모델은 무료·오프라인이라는 큰 장점이 있다.

## 6. 이 결과를 채점기 개선에 반영한 것

레퍼런스를 채점하다 **채점기 버그**를 하나 찾았다.

`design-tokens.json` 을 `{"space": {"--sp-1": "4px"}}` 로 쓰면
간격 단계를 **0개로 셌다.** 잎 키(`--sp-1`)만 보고 그룹 이름(`space`)을 버렸기 때문이다.
`--sp-*` 는 흔하고 올바른 작명인데 미달로 잡혔다.

→ `checks._designer` 가 **부모 그룹 이름을 함께** 보도록 고쳤다.
좋은 결과물로 채점기를 검증하면 이런 것이 드러난다.
