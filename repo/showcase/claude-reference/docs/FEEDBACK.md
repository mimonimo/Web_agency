# 운영 관찰 — 별빛공방 (S10 고객)

실제 화면을 써 보고 나온 문의다. 지어낸 불만은 적지 않았다.

## 문의 1 — 예약을 취소하고 싶다

날짜를 잘못 골라서 다시 잡고 싶은데 방법이 없다.
공방에 전화해야 하는데, 전화를 줄이려고 만든 사이트라 앞뒤가 안 맞는다.
→ **예약번호 + 연락처 뒷자리**로 취소할 수 있으면 좋겠다.

## 문의 2 — 어떤 그릇을 만드는지 보고 싶다

설명은 읽었는데 결과물이 상상이 안 된다. 특히 "유약 놀이" 는 뭘 하는 건지 애매하다.
→ 클래스마다 **완성 사진 2~3장**. 사진 제작이 이번 범위 밖이었던 건 안다.

## 문의 3 — 여러 날짜를 한눈에 보고 싶다

날짜를 하나씩 바꿔 가며 남은 자리를 확인해야 한다.
주말에 자리 있는 날을 찾으려면 여섯 번을 눌러야 한다.
→ **주간 달력**으로 이번 주 빈자리를 한 번에 보여 주면 좋겠다.

## 문의 4 — 단체 문의

회사 워크숍으로 12명이 가고 싶은데 정원이 6명이라 접수가 안 된다.
→ 정원을 넘으면 "단체는 전화 주세요 010-2847-1103" 안내가 뜨면 좋겠다.
