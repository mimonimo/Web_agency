# SOW — 별빛공방 원데이 클래스 예약

> S1 영업. 하기로 한 것과 **안 하기로 한 것**을 나눠 못 박는다.

## 포함 범위

1. 클래스 목록 화면 — 4개 클래스, 가격·시간·정원 표시
2. 클래스 상세 화면 — 설명·준비물·예약 연결
3. 예약 화면 — 날짜·시간대·인원·연락처 접수, 예약번호 발급
4. 예약 확인 화면 — 예약번호로 조회
5. 문의 화면 — 이름·연락처·내용 접수
6. 휴대폰 대응 (390px 폭까지)

## 제외 범위

1. **온라인 결제** — 방문 시 현장 결제. 결제 연동을 하지 않는다.
2. **회원가입·로그인** — 이름과 연락처만 받는다. 비밀번호를 다루지 않는다.
3. **후기 게시판** — 인스타그램으로 대체한다.
4. **관리자 화면** — 예약 확인은 공방에서 직접 한다.
5. **문자·이메일 발송** — 자동 알림을 보내지 않는다.
6. **공휴일 처리** — 월요일 휴무만 반영한다.

## 전제

- 클래스 4종·가격·정원·운영시간은 고객이 확정해 주었다 (주문서 표 그대로).
- 사진은 이번에 제작하지 않는다. 색과 도형으로 표현한다.
- 교실 환경에 인터넷이 없으므로 외부 폰트·이미지·CDN 을 쓰지 않는다.

## 미정

- 예약 취소 정책 — 고객이 아직 정하지 않았다. 이번 범위에서 제외한다.
