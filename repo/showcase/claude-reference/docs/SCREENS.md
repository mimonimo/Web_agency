# SCREENS — 별빛공방

> S2 기획. **여기 적은 화면 수가 구현 단계의 목표가 된다.**
> 한 페이지 안에서 `<section>` 으로 전환한다 (인터넷 없이 도는 정적 사이트).

## 클래스 목록

- 보이는 것: 공방 소개 한 줄, 클래스 카드 4개(이름·가격·소요시간·정원·한 줄 설명)
- 할 수 있는 것: 카드를 눌러 상세로 이동, 상단 [예약하기] 로 바로 예약
- 이동: 상세 / 예약 / 확인 / 문의

## 클래스 상세

- 보이는 것: 클래스 이름, 가격, 소요시간, 정원, 설명 3~4줄, 준비물 목록
- 할 수 있는 것: [이 클래스 예약하기](그 클래스가 선택된 채로), [목록으로]
- 이동: 목록 / 예약

## 예약

- 보이는 것: 클래스 선택, 날짜, 시간대(10:00/14:00/19:00), 인원, 이름, 연락처,
  남은 자리 안내, 접수 결과(예약번호)
- 할 수 있는 것: 값을 채워 [예약하기]. 조건을 못 채우면 무엇이 잘못됐는지 알려준다
- 이동: 목록 / 확인

## 예약 확인

- 보이는 것: 예약번호 입력칸, 조회 결과(클래스·날짜·시간·인원·이름)
- 할 수 있는 것: [조회]. 방금 예약한 사람은 자동으로 채워져 있다
- 이동: 목록 / 예약

## 문의

- 보이는 것: 이름·연락처·내용 입력, 보낸 문의 목록
- 할 수 있는 것: [보내기]
- 이동: 목록
