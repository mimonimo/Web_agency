# UI 가이드 — 별빛공방

## 색을 이렇게 고른 이유

주문서: *"흙과 유약 같은 느낌. 차분하고 따뜻한. 손으로 빚은 것처럼 조금 투박해도."*

| 낱말 | 옮긴 값 | 어디에 |
|---|---|---|
| 흙 | `#A65E3C` 테라코타 | 주 버튼, 강조 |
| 굽고 난 흙 | `#7D4227` 짙은 테라코타 | 버튼 눌림, 가격 |
| 유약 | `#5B7A6E` 차분한 청록 | 보조 강조, 포커스 링 |
| 초벌 그릇 | `#F5F0E8` 오프화이트 | 배경 |
| 백자 | `#FFFDF9` | 카드 표면 |

**차가운 파랑·형광은 쓰지 않는다.** 반짝이는 그라디언트·네온도 쓰지 않는다.
주문서가 "화려한 건 안 맞는다" 고 했다.

## 대비 (WCAG)

| 조합 | 비율 | 판정 |
|---|---|---|
| `--c-ink` on `--c-bg` | 12.4:1 | AAA |
| `--c-ink-soft` on `--c-bg` | 5.8:1 | AA |
| `--c-surface` on `--c-clay` | 5.1:1 | AA |

본문·버튼 모두 4.5:1 이상.

## 컴포넌트

### 버튼
- **주 버튼** — 배경 `--c-clay`, 글자 `--c-surface`, 최소 높이 44px(터치 목표),
  모서리 `--rd-sm`, 눌리면 1px 내려간다
- **보조 버튼**(`.btn-ghost`) — 투명 배경, 테두리 `--c-line`
- **큰 버튼**(`.btn-lg`) — 52px, 화면당 하나만. 주 행동에만
- 비활성은 `--c-clay-soft` — 색이 옅어져 눌 수 없음이 보인다
- 포커스 링은 `--c-glaze` 3px. **키보드로도 지금 어디인지 보여야 한다**

### 입력
- 최소 높이 44px, 배경은 `--c-bg` (카드보다 살짝 어둡게 해서 입력칸임을 표시)
- 포커스: 테두리 `--c-glaze` + 3px 후광
- 모든 입력에 `<label for>`. 자리표시자로 라벨을 대신하지 않는다

### 카드
- 배경 `--c-surface`, 테두리 `--c-line`, 모서리 `--rd-md`
- 그림자는 아주 옅게(`--sh-1`). 호버에서 2px 떠오른다
- 클래스 카드는 `<button>` 이다. 클릭되는 `<div>` 를 만들지 않는다

### 로고
이미지 파일을 쓰지 않는다. 물레 위의 그릇을 CSS 도형으로 그렸다
(`border-radius` 비대칭 + 안쪽 그림자).

## 간격

`--sp-1`(4) ~ `--sp-6`(64) 여섯 단계만 쓴다. 임의의 px 을 쓰지 않는다.

## 반응형

640px 이하에서 2열 폼이 1열로, 내비게이션이 가로 꽉 차기로 바뀐다.
`prefers-reduced-motion` 을 존중해 전환을 끈다.
