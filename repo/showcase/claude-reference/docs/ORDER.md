## 목적

동네 사람들이 **전화하지 않고** 원데이 클래스를 예약할 수 있게 한다.
지금은 인스타그램 DM 으로 받는데, 같은 시간대에 두 명이 겹치는 일이 잦다.

## 필요 기능

1. 클래스 목록 — 어떤 수업이 있는지 한눈에
2. 클래스 상세 — 무엇을 만드는지, 얼마나 걸리는지, 가격
3. 예약 — 날짜와 시간대를 고르고 신청
4. 예약 확인 — 내 예약번호로 조회
5. 문의 — 간단한 질문 남기기
