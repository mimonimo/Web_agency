판정: 통과

## 주문 대비 확인

| 내가 부탁한 것 | 됐나 |
|---|---|
| 전화하지 않고 예약할 수 있게 | ✅ 날짜·시간 고르고 이름·연락처만 넣으면 끝난다 |
| 같은 시간에 두 명이 겹치지 않게 | ✅ 남은 자리가 실시간으로 보이고, 넘치면 접수가 안 된다 |
| 클래스 4개가 다 보이게 | ✅ 물레·컵·유약·커플 모두 있다 |
| 무엇을 만드는지 알 수 있게 | ✅ 상세에 설명과 준비물이 있다 |
| 예약 확인 | ✅ 번호로 조회된다. 예약 직후에는 번호가 이미 채워져 있어 편하다 |
| 문의 | ✅ |
| 흙과 유약 같은 느낌 | ✅ 크림 바탕에 테라코타 버튼. 우리 가게 색이랑 맞다 |
| 반짝이거나 화려하지 않게 | ✅ 그라디언트도 형광색도 없다 |
| 휴대폰으로 | ✅ 폭을 줄여도 안 깨진다. 카드가 한 줄씩 쌓인다 |
| 월요일 휴무 | ✅ 아예 못 고르게 되어 있다 |

## 좋았던 것

- 로고를 그림 파일 없이 만들었는데 물레 위 그릇처럼 보인다.
- 남은 자리가 숫자로 보이는 게 좋다. "몇 자리 남았어요?" 전화가 줄겠다.
- 가격이 `45,000원` 으로 나와서 읽기 쉽다.

## 아쉬운 것 (반려는 아님)

- 클래스 **사진이 없다.** 어떤 그릇을 만드는지 감이 잘 안 온다.
  처음부터 "사진은 이번에 제작하지 않는다" 고 합의했으니 다음에 부탁하겠다.
- 예약을 **취소**할 방법이 없다. 이것도 범위 밖이었다. 다음 주문으로 내겠다.
