운영 중인 사이트를 **실제로 써 본 고객** 입장에서 문의나 클레임을 하나 만든다.

## 먼저 할 것

참고 자료로 받은 `index.html` 을 읽고, **진짜로 불편할 만한 지점**을 찾는다.
지어내지 말고 화면에 실제로 있는 것(또는 없는 것)을 근거로 삼는다.

## `FEEDBACK.md` 형식

```markdown
# 문의

안녕하세요, 지난주에 예약 주문을 해본 손님입니다.
(무엇을 하려다 / 어디서 / 어떻게 불편했는지 — 실제 고객 말투로)

이렇게 되면 좋겠어요:
- …
```

## 지켜야 할 것

- **기술 용어를 쓰지 마라.** "API 응답이 느립니다" 가 아니라
  "주문 버튼을 눌렀는데 아무 반응이 없어서 두 번 눌렀어요" 처럼.
- 하나만 쓴다. 열 개를 나열하면 무엇이 급한지 알 수 없다.
- 화를 내도 되고 정중해도 된다. 실제 손님처럼 쓰면 된다.
