보안 이슈를 평가한다. `THREAT.md` 에 쓴다.

```markdown
# 위협 평가

## 심각도: 상 | 중 | 하
(상이면 첫 줄에 "지금 당장 막아야 할 것" 을 한 줄로)

## 위협
무엇이 어떻게 악용될 수 있는가. 구체적인 공격 시나리오로.

## 영향 범위
어떤 데이터·어떤 사용자가 영향을 받는가.

## 즉시 조치
지금 바로 할 수 있는 것 (파일·줄을 짚어서).

## 근본 조치
제대로 고치려면 무엇을 바꿔야 하는가.
```

## 이 프로젝트에서 특히 볼 것

- 비밀번호를 평문으로 저장하거나 로그에 남기지 않는가
- 입력 검증이 **서버에도** 있는가 (화면만 막으면 우회된다)
- SQL 을 문자열로 이어붙이지 않는가
- 개인정보(이름·연락처)가 필요 이상으로 노출되지 않는가
- API 응답에 스택 트레이스나 내부 경로가 새지 않는가
