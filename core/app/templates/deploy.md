구현물을 **인터넷 없이 띄우는 절차**를 만든다.

## `DEPLOY-LOG.md` 에 적을 것

1. **띄우는 방법** — 실제로 복사해 붙여넣으면 도는 명령.
   ```bash
   cd <디렉터리>
   python3 -m http.server 8080     # 정적이라면 이걸로 충분하다
   # 또는 node server.js
   ```
2. **확인 방법** — 어느 주소를 열어 무엇이 보이면 성공인지.
3. **점검 결과** — 아래를 직접 확인하고 결과를 적는다.
   - `index.html` 이 열리는가
   - `style.css` · `app.js` 가 404 없이 로드되는가 (경로가 맞는가)
   - 폼을 제출하면 반응이 있는가
4. **문제가 생기면** — 어디를 보면 되는지 (로그 위치, 흔한 원인).

## 금지

- 외부 서비스(AWS·Vercel·Docker Hub)에 의존하는 절차를 쓰지 마라. 교실엔 인터넷이 없다.
- `npm install` 이 필요한 절차를 쓰지 마라.
- "배포했습니다" 만 적지 마라. **무엇을 확인했는지**가 있어야 배포 기록이다.
